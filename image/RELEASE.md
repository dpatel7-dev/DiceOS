Dice for Raspberry Pi (64-bit). Write **dice-arm64.img.xz** onto a microSD card or an NVMe drive with Raspberry Pi Imager ("Use custom"), then drop your dice.json from https://djp7.pythonanywhere.com/dice onto the card's "bootfs" drive.

Made for the Raspberry Pi 5 and 4. The user is `dice`, password `dice`, until you change it.
